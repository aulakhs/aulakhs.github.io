Hermes Agent Starter Pack

Build Your Own Personal AI Operating System

A practical set of instructions and copy/paste prompts for turning a fresh Hermes install into a useful personal assistant: memory, skills, scheduled agents, Telegram access, project workflows, and a local knowledge base.

Hermes GitHub Source repo and installation script Hermes Docs Setup, tools, gateway, cron, skills
May 15, 2026 · starter guide

If you just installed Hermes for the first time, do not start by copying someone else’s full setup. Copy the pattern instead: durable memory, a local knowledge base, reusable skills, scheduled jobs, messaging access, and small deterministic scripts for anything repetitive.

Install Hermes

curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
hermes setup
hermes doctor

After setup, start Hermes with:

hermes

Then paste the prompts below one by one.

1. Bootstrap your personal context

Use this first so Hermes learns who you are and how to work with you.

Help me turn this Hermes install into my personal assistant.

First, ask me for:
1. My name, location, timezone, email, and preferred communication style.
2. My work/career goals.
3. My recurring tasks.
4. The tools I use daily.
5. What kinds of things I want you to remember.
6. What I do NOT want automated without explicit confirmation.

Then create a compact user profile and save durable preferences to memory. Keep it concise and useful; do not save temporary task state.

2. Build a local knowledge base

A filesystem knowledge base is portable across agents and easy to back up.

Create a local knowledge base for me under ~/knowledge with this structure:

- identity/
  - about.md
  - preferences.md
  - career.md
- memory/
  - long-term.md
  - decisions.md
- intel/
  - latest.md
- skills/
  - briefing.md
  - content-creation.md
  - job-search.md
- tools/
  - inventory.md
- config/
  - architecture.md

Ask me the minimum questions needed, then create the files with useful starter content. Make the knowledge base vendor-agnostic so any AI agent can read it later.

3. Create reusable skills

Skills are the compounding layer: reusable operating procedures Hermes can load when a task matches.

Help me create my first Hermes skills.

I want skills for:
1. Daily briefing
2. Job search monitoring
3. Content drafting
4. Personal research
5. Project/code work

For each skill:
- Ask what my preferred workflow is.
- Create a clear SKILL.md with trigger conditions, steps, commands, quality bar, and verification.
- Keep secrets out of the skill.
- Save the skills in the right Hermes skills directory.
- Then show me how to list and load them.

Useful skill commands:

hermes skills list
hermes skills search briefing
hermes skills install <skill-id>
hermes -s <skill-name>

4. Make Hermes available from Telegram or chat

Gateway mode gives you ambient access to the same local agent from messaging platforms.

hermes gateway setup
hermes gateway install
hermes gateway start
hermes gateway status

Then message the bot in Telegram:

/sethome

Prompt Hermes to set expectations for chat behavior:

I want you to be my personal assistant over Telegram.

Set expectations:
- Be concise.
- Use tools before asking me to repeat information.
- Do not send emails, post publicly, or message other people without explicit approval.
- For scheduled jobs, deliver results here.
- If something fails in a background job, proactively tell me with error details and next action.

Messaging docs: Hermes messaging platform guide.

5. Create scheduled agents and cron jobs

Use cron for work that should happen without you prompting every time.

Create a daily morning briefing job for me.

Schedule: every weekday at 7:30am local time.

Include:
- Weather
- Calendar
- Important unread email summary
- Relevant news for my work
- Any urgent system or task reminders
- One recommended action for the day

Make it concise but useful. Deliver to my home Telegram channel. Use a cheaper/faster model unless the work needs deep reasoning.

Useful cron commands:

hermes cron list
hermes cron create "every weekday 7:30am"
hermes cron run <job-id>
hermes cron pause <job-id>
hermes cron remove <job-id>

Cron docs: Hermes cron guide.

6. Build agents for coding and projects

Give Hermes an execution standard so it inspects, implements, verifies, and reports clearly.

I want you to help me build software projects like a practical engineering partner.

Default workflow:
1. Inspect the repo before changing anything.
2. Find project instructions: README, AGENTS.md, CLAUDE.md, package files, tests.
3. Make a small plan.
4. Implement quickly.
5. Run tests or a meaningful verification.
6. Summarize exactly what changed.

When a task is large, use subagents or background work where appropriate. Do not just describe what you would do — actually do it.

For a new project:

Create a new project for [describe idea].

Requirements:
- Pick a simple stack unless I specify one.
- Create the repo/files.
- Add a README.
- Add a minimal test or smoke check.
- Run it locally and verify it works.
- Tell me the exact next step.

7. Create a personal RAG / “save this” brain

Start simple: local storage, URL ingestion, summaries, chunks, embeddings, and search.

Design and build me a local personal knowledge base/RAG system.

Requirements:
- Runs locally.
- Ingests URLs and text notes first.
- Stores source, summary, chunks, entities, and embeddings.
- Uses SQLite for storage.
- Uses a local embedding model if possible.
- Provides CLI commands:
  - kb ingest <url-or-file>
  - kb search "<query>"
  - kb status
- Add tests for chunking, search, and ingestion.
- Keep API keys out of committed files.

Start with a simple working version, not an overbuilt architecture.

GitHub and sharing

The public repo to share is NousResearch/hermes-agent. If someone else has a personal knowledge-base repo, treat it as private by default. It may include identity, preferences, internal notes, job-search intel, or other sensitive material.

8. The single best “teach Hermes how I work” prompt

If you only paste one prompt after installing Hermes, paste this one.

Interview me and turn the answers into a working Hermes setup.

Goal: make you useful as my personal AI assistant.

Create:
1. A compact user profile.
2. Durable memory entries for stable preferences.
3. A ~/knowledge folder with identity, memory, intel, skills, tools, and config.
4. Three reusable Hermes skills:
   - daily briefing
   - project execution
   - personal research
5. One scheduled job that delivers a useful daily update.
6. A short README explaining how my setup works.

Important:
- Ask only necessary questions.
- Prefer simple local files over complex infrastructure.
- Never store secrets in markdown.
- Verify every file you create.
- At the end, show me exact commands to use the system.

The pattern that compounds

  • Memory for stable preferences and durable facts.
  • ~/knowledge for deeper context the agent can read and update.
  • Skills for repeatable workflows.
  • Cron for scheduled agents.
  • Gateway / Telegram for ambient access.
  • Local scripts for deterministic work that does not need model tokens.

That is the real setup. The individual prompts will change; the operating model is what keeps getting more useful.
